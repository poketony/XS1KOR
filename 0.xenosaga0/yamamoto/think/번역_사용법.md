# 이 폴더에서 번역하기

편집할 파일은 **이 폴더의 `translations.json`**이다. 다른 도구 폴더는 사용하지 않는다.

원문 569개가 1,192개 위치에 연결되어 있다. 각 항목의 `translation`을 한 번 수정하면 `locations`에 적힌 모든 위치에 적용된다. 공백·개행·제어문자가 다른 원문은 서로 다른 항목으로 보존했다.

- 수정할 것: `translation`
- 유지할 것: `id`, `source`, `locations`, `original_sha256`, `version`
- `\n`은 개행이다. 전각/반각 공백도 그대로 구분한다.
- `\u0019` 등은 제어문자다. 뜻을 모르는 제어문자는 유지한다.
- `null`은 원문 유지, `""`는 빈 번역이다.

`translations.json`을 저장한 뒤 **`RebuildThink.bat`을 더블클릭**하면 BIN 빌드와 `thinktool.py patch all`을 차례로 실행한다. 실패하면 다음 단계로 넘어가지 않고 오류를 표시한다. 모든 대상 아카이브를 먼저 검증하고, 각 `.a`는 임시 파일 검증 후 교체한다. 전체 작업의 일괄 롤백은 아니므로 도중에 중단되면 오류를 해결하고 다시 실행한다.

매핑이 없는 BIN도 빌드되지만 `.a`에 적용되지는 않는다. ISO 재생성은 별도다.

BIN만 검사하거나 빌드하려면 이 폴더에서 실행:

```powershell
python -B think_translate.py check
python -B think_translate.py build
```

`check`는 파일을 변경하지 않는다. `build`는 `.bin.ori`에서 매번 새로 만들어 **이 폴더의 thinkNNN.bin 100개를 갱신**한다. 기존 BIN을 입력으로 쓰지 않으므로 반복 빌드해도 확장이 누적되지 않는다. 배치 파일은 이후 `..\scene`의 매핑된 `.a`를 재구성한다. 빌드 보고서는 `codex-lab/think-reports`에 기록한다.

긴 번역은 자르지 않고 파일 끝으로 확장한다. 파일 전체 16KB를 넘거나 원문·위치가 어긋나면 출력 전에 실패한다. 화면 폭·개행·표시 시간은 실제 게임에서 확인해야 한다.

## 한 위치만 다른 번역이 필요할 때

해당 항목의 `overrides`에 `locations`에 있는 키를 그대로 적는다.

```json
"overrides": {
  "thinkNNN.bin:0xOOOO": "이 위치에만 적용할 번역"
}
```

위 키는 형식 예시다. 실제 `locations`의 값을 복사한다. 나머지 위치는 공통 `translation`을 사용한다. 예외를 없애려면 해당 키를 지운다.

기존 `thinkNNN.txt`는 원문 참고 자료이며 이 새 빌드의 입력이 아니다. 예전 `think_patch.py` 대신 `think_translate.py`를 사용한다.
